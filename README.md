| Acción | Atajo de Teclado / Control |
|---|---|

| **Retroceder diapositiva** | `←` (Flecha Izquierda), `RePág` o Clic en botón `‹ Anterior` |

| **Ir a la última diapositiva** | Tecla `Fin` (`End`) |
